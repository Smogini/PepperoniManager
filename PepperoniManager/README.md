# Struttura iniziale applicazione web

## Tecnologie
- PHP
- HTML
- CSS
- Bootstrap 5
- JavaScript

## Avvio rapido

1. Copia il progetto dentro:
   - htdocs (XAMPP)
   - www (WAMP)

2. Avvia Apache

3. Apri:
   http://localhost/webapp_template

## Struttura

- index.php -> pagina principale
- backend/ -> logica PHP
- assets/css -> fogli di stile
- assets/js -> JavaScript
